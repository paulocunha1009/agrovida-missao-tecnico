# Operação AgroVida — Do campo ao computador

Atividade de Arquitetura e Manutenção de Computadores: armazenamento, placa-mãe, caminho dos dados e diagnóstico técnico.

## Usar

Abra `index.html` no navegador. Todos os recursos estão incorporados ao arquivo. A versão baixada funciona offline. O progresso fica no navegador de cada dispositivo; não é enviado ao professor nem sincronizado entre computadores. Use o relatório para entregar as evidências.

## Publicar no GitHub Pages

1. Envie `index.html` e `.nojekyll` para a raiz do repositório.
2. Em Settings > Pages, selecione Deploy from a branch.
3. Escolha a branch que contém os arquivos e a pasta / (root), depois Save.
4. Use o endereço informado pelo GitHub Pages.

A versão online precisa de conexão para ser aberta. Para uso sem internet, baixe o HTML antes. A versão anterior e o HTML com nome original são cópias de trabalho e não são necessários à publicação.
